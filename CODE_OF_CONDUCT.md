# Code of Conduct

We want KYC Form Hub to be a welcoming and productive community for everyone.

## Our Standards

Examples of behavior that contributes to a positive environment:

- Being respectful and inclusive in communication.
- Giving constructive feedback gracefully.
- Accepting constructive criticism with openness.
- Focusing on what is best for the project and its users.
- Showing empathy towards others.

Examples of unacceptable behavior:

- Harassment, discrimination, or intimidation of any kind.
- Trolling, insulting comments, or personal attacks.
- Publishing others' private information without permission.
- Disruptive behavior that hinders collaboration.

## Enforcement

Project maintainers have the right and responsibility to remove, edit, or reject contributions or comments that violate this code of conduct. Serious or repeated violations may result in a temporary or permanent ban from the project spaces.

## Scope

This code applies within all project spaces (issues, pull requests, discussions, chats) and when representing the project in public.

## Reporting

If you experience or witness unacceptable behavior, please contact the maintainers by opening a private issue or emailing the project maintainers.
