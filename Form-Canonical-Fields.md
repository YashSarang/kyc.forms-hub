# Form Canonical Fields

This document lists the complete canonical KYC field set used by the benchmark. Fields marked with `*` are required in the full `baseline` scenario; individual level/issue scenarios may use subsets.

## Personal Identity
- Full Name*
- First Name*
- Middle Name
- Last Name
- Preferred Name
- Gender*
- Date of Birth*
- Age (auto-calculated)
- Nationality*
- Marital Status*

## Contact
- Mobile Number*
- Alternate Mobile
- Landline
- Email*
- Current Address
    - Address Line 1*
    - Address Line 2
    - Landmark
    - City*
    - District*
    - State*
    - PIN Code*
    - Country*
- Permanent Address (same sub-fields as current address)
    - Same-as-current-address checkbox

## Identity Documents
- Aadhaar Number (with upload option)
- PAN Number (with upload option)
- Passport Number (with upload option)
- Driving Licence Number (with upload option)
- Voter ID (with upload option)

## Banking
- Bank Name
- Branch
- Account Number
- IFSC Code
- Account Type

## Employment
- Occupation
- Employment Type
- Employer Name
- Designation
- Industry

## Financial Profile
- Annual Income
- Income Range
- Sources of Income
- Net Worth
- Investment Experience
- Politically Exposed Person (PEP)
- Beneficial Owner

## Nominee
- Nominee Name
- Relationship
- Date of Birth
- Share Percentage

## Family Details
- Father's Name
- Mother's Name
- Spouse Name
- Guardian Name
- Emergency Contact
    - Name
    - Relationship
    - Address
    - Phone Number
